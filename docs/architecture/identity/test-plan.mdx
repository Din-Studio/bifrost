本页把 PRD《Bifrost OSS 用户体系与 Casdoor User Provisioning》的"验收场景（开发前固定）"表与复审报告的"建议固定的核心验收门槛"表合并为一张，并给每行分配稳定 ID。其它契约文档（`auth-and-credentials`、`identity-binding-and-sync`、`rbac-matrix`、`casdoor-bridge`）只引用 ID，不重复描述。

ID 形如 `AC-<域>-<序号>`。域：`CFG`（Phase 1 配置）、`AUTH`、`SESS`、`BIND`、`SYNC`、`RBAC`、`DEAC`、`BRIDGE`、`SCIM`、`ATTR`、`UI`。

## 测试面与命令

| 测试面 | 位置 | 命令 |
|---|---|---|
| framework/identity 单测 | `framework/identity/**/*_test.go` | `make test-framework`（或 `cd framework && go test ./identity/...`） |
| transport 集成 | `transports/bifrost-http/{handlers,lib}/*_test.go` | `make test-http-transport` |
| governance | `plugins/governance/*_test.go` | `make test-governance TESTCASE=<Name>` |
| Playwright | `tests/e2e/features/<flow>/` | `make run-e2e FLOW=<flow>` |
| SCIM 合规脚本 | `tests/e2e/api/`（Phase 4 新增） | Phase 4 定义 |
| 计时验收 | 手工或脚本，记录时间戳 | Phase 3/4 定义 |

## 零回归门槛

"现有回归全绿"只证明**旧行为未回归**，不证明新契约成立。以下文件是每个阶段合并前必须全绿的零回归门槛：

- `transports/bifrost-http/handlers/middlewares_test.go`
- `transports/bifrost-http/handlers/governance_test.go`
- `transports/bifrost-http/handlers/mcpserver_test.go`
- `plugins/governance/permits_test.go`
- `transports/bifrost-http/lib/config_test.go`（`TestConfigSchemaSync*`）

命令：`make test-http-transport` 与 `make test-governance`。
